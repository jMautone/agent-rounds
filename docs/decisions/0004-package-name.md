# 4. Package and binary name: agent-rounds

Date: 2026-11-14 · Status: accepted

## Context

The working name was `ronda` ("round" in Spanish), but `ronda` is taken on npm and the project is public and in English.

## Decision

The npm package, the repository and the binary are all `agent-rounds`. The name was free on npm on 14 November 2026.

## Consequences

- `npx agent-rounds …` works without a separate binary name to remember.
